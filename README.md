# A Door for the Word — Ministry Website

A static GitHub Pages website reconstructed from the WordPress export dated November 15, 2026.

## Included
- Home / mission / articles / contact / four audio teachings
- `Adam & Christ and Divine Life` article from the WordPress export
- Four user-selected MP3 recordings in `assets/audio/`
- No video files and no fifth audio recording

## Publish via GitHub Pages
1. Upload all contents **inside this folder** to the root of the repository `altarlifeKash/ADoorForTheWord`.
2. In Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)`, and save.
3. Preview the site at `https://altarlifekash.github.io/ADoorForTheWord/` before adding a custom domain.
4. Only after reviewing and preserving existing DNS settings, connect `adoorfortheword.org`.

## Important before DNS cutover
- PDF resources currently link to the old hosting; retrieve actual PDFs and update links before shutting that hosting down.
- The previously approved redesigned logo was not supplied as a file in this upload, so the design uses a typographic wordmark as a placeholder.
- Two long spoken-word recordings were re-encoded at 32 kbps mono to fit GitHub's 25 MiB per-file web-upload limit. Originals are unchanged in the user uploads.
- The old WordPress contact page listed a street address and phone number. These are intentionally omitted pending publication review.
- Test all links and audio playback before changing DNS.
- GitHub Pages hosts static websites; WordPress forms and shortcodes will not work without replacement services.
